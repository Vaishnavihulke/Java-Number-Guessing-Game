# 🎯 Java Number Guessing Game

A simple and interactive console-based Number Guessing Game developed using Java.

## 📌 About the Project

The computer randomly selects a number between 1 and 100, and the player has 7 attempts to guess the correct number.

After every incorrect guess, the game provides a hint telling the player whether the guessed number is too high or too low.

## ✨ Features

- Random number generation
- Number range from 1 to 100
- Maximum 7 attempts
- Too high / too low hints
- Input validation
- Score calculation
- Play again option
- Game summary
- User-friendly console interface

## 🛠️ Technologies Used

- Java
- Java Scanner
- Java Random
- Conditional statements
- Loops
- Exception/Input validation

## ▶️ How to Run

Make sure Java JDK 21 or later is installed.

Compile the program:

```bash
javac NumberGuessingGame.java
```

Run the program:

```bash
java NumberGuessingGame
```

## 🎮 How to Play

1. Run the program.
2. The computer selects a random number between 1 and 100.
3. Enter your guess.
4. Follow the hints.
5. Try to guess the number within 7 attempts.
6. Choose whether you want to play again.
