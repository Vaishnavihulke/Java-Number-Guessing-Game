# 🎯 Java Number Guessing Game

A simple and interactive **console-based Number Guessing Game** developed using Java. The game challenges the player to guess a randomly generated number within a limited number of attempts.

## 📌 About the Project

The computer randomly selects a number between **1 and 100**, and the player gets **7 attempts** to guess the correct number.

After every incorrect guess, the game provides a helpful hint indicating whether the guessed number is **too high** or **too low**.

The game also includes input validation, score calculation, a play-again option, and a final game summary.

## ✨ Features

- 🎲 Random number generation
- 🔢 Number range from 1 to 100
- 🎯 Maximum of 7 attempts
- 💡 Too high / too low hints
- ✅ Input validation
- 🏆 Score calculation
- 🔄 Play again option
- 📊 Game summary
- 💻 User-friendly console interface

## 🛠️ Technologies Used

- **Java**
- **Java Scanner**
- **Java Random**
- **Conditional statements**
- **Loops**
- **Exception handling / input validation**

## ▶️ How to Run

### Prerequisites

Make sure **Java JDK 21 or later** is installed on your system.

### Compile the Program

```bash
javac NumberGuessingGame.java
```

### Run the Program

```bash
java NumberGuessingGame
```

## 🎮 How to Play

1. Run the program.
2. The computer generates a random number between 1 and 100.
3. Enter your guess.
4. Follow the hints provided by the game.
5. Try to guess the number within 7 attempts.
6. Check your score and game summary.
7. Choose whether you want to play again.
